Projects

  1. HomeBeacon

    Founder & Inventor

    2025 – Present

    A full-stack IoT home-monitoring platform I built end to end: a native Kotlin beacon client, a Flutter app across Android, iOS and Web, and a Python Firebase Cloud Functions backend. A hierarchical Firestore schema (zip → user → date → heartbeats) keeps high-frequency writes fast, and event-driven Cloud Functions check every heartbeat against a configurable health window — staying quiet while a beacon is healthy, and reaching out the moment it goes silent. Missed pings escalate through tiered yellow/orange/red alerts that name the likely cause: charging disconnect, lost connectivity, GPS or gyroscope drift.

    • Kotlin
    • Flutter
    • Firebase
    • Python
    • IoT

  2. Matrix-Multiplication Accelerator

When synthesis constraints got in the way, I re-architected the multiplier datapath around shift-based arithmetic.
