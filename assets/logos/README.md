Notes:
- PNG with a **transparent background** looks best. SVG also works — if you use
  SVG, change the `src` in `index.html` to match (e.g. `raytheon.svg`).
- Roughly square, around 256×256 up to 512×512, is plenty.
- Any file you don't add simply falls back to a lettered monogram tile, so the
  site never shows a broken image. Add them one at a time if you like.
